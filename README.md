# 🤔 ABSÜRT VAROLUŞSAL KRİZ ÜRETECİ 2026

## Resmi Dokümantasyon - Ciddiye Alınız (Ya da Almayınız)

Bu repository, insanlığın en temel sorununa çözüm üretmek amacıyla oluşturulmuştur: **"Şu an ne yapıyorum ve neden?"** sorusuna cevap vermek.

### Özellikler
- Gerçekten çalışan Python kodu
- Rastgele varoluşsal krizler üretir
- Dramatik bekleme efektleri içerir
- Ruhunuzu sorgulatır (garantisi yoktur)
- Kahve içmez (kahve içenler başka repoya gitsin)

### Kurulum ve Kullanım

```bash
git clone https://github.com/Tentivory/absurd-varolussal-kriz-ureteci-2026.git
cd absurd-varolussal-kriz-ureteci-2026
python3 kriz_ureteci.py
```

Çıktı örneği:
```
🤔 Varoluşsal Kriz Makinesi başlatılıyor
...

```

- Dil: Python 3
